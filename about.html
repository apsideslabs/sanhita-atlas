About Sanhita Atlas

An independent research platform for the Bharatiya Nyaya Sanhita, 2023, built as an open static site with no tracking and no login.

Open sourceMIT

Why it exists

On 1 July 2024 India replaced three statutes that had governed its criminal justice system for over a century. Every section number moved. Practitioners, students and journalists spent the following months converting references in their heads — 302 to 103, 420 to 318, 124-A to 152.

This platform is a reference for that conversion, and for the structure of the new code. It is not affiliated with the Government of India, any court, or any law firm.

What it is built with

Stack

Static, no server

Hand-written HTML and CSS, with Alpine.js for the interactive parts, Fuse.js for search, and Chart.js for the chapter distribution. No framework, no build runtime, no database.

Hosting

GitHub Pages

The site is served directly from the repository. Every page is a plain HTML file, so it loads without JavaScript and prints cleanly.

Privacy

No tracking

No analytics, no cookies, no third-party scripts beyond a font CDN and the libraries above. Search runs entirely in the browser against a static index.

Licence

MIT

The code is MIT licensed. The statutory text it indexes is published by the Government of India and is not claimed by this project.

Corrections

If a section number, punishment or mapping is wrong, the correction is welcome — open an issue on the repository with the provision and the source. Corrections are reviewed against the Gazette text.
